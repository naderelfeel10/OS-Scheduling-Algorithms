# OS-Scheduling-Algorithms

modify MINIX 3 to support four scheduling algorithms: Round Robin (RR), Shortest Job First (SJF), Priority-Based, and Multi-Level Feedback Queue (MLFQ). Users should be able to configure scheduling parameters via a configuration file (e.g., /etc/scheduler.conf).

For implementation:

Modify the MINIX 3 scheduler to select the appropriate algorithm.

Implement each algorithm with proper process selection and preemption rules.

Read settings from the configuration file to apply user-defined scheduling parameters.

Measure performance by calculating average turnaround time and waiting time for real processes.

Compare the algorithms based on execution results and document findings in a detailed report.
